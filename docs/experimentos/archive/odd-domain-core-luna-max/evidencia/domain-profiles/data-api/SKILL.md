# Núcleo experimental de skill de dominio

Aplica esta skill solo al dominio correspondiente y al proyecto afectado. El agente
principal conserva la coordinación integral, la autorización y el cierre.

**Antes de analizar decisiones o modificar ese dominio, lee `implementation.md` de
esta carpeta.** Contiene los criterios originales de implementación sin resumirlos.
Consulta los contratos/componentes pertinentes del proyecto; no los sustituyas por
suposiciones. Reutiliza contexto vigente y abre solo fuentes adicionales necesarias.

Una consulta o implementación NO autoriza crear carpetas, inventarios ni sincronizar
documentación. Solo si se autoriza trabajo documental, lee además `documentation.md`
y las plantillas que ese trabajo requiera. El mantenimiento canónico sigue a cargo
del responsable documental; no iniciar ese flujo al programar una característica.

Ante una duda de alcance o contexto entre referencias, consulta `original-contract.md`,
que conserva el texto íntegro original en su orden. No omitas una regla necesaria
para ahorrar. Protege secretos y datos sensibles, no inventes fuentes/valores ni
resultados, y respeta permisos y alcance. No releas lo que siga disponible y vigente.
